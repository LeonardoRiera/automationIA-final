# Automatización con IA para Soporte – Imperio Tickets

Proyecto final del curso de IA Automation.

Automatización desarrollada en Make para gestionar consultas de soporte, combinando Gmail, Airtable, Groq, Telegram, RAG, HITL y manejo de errores.

## Resumen

El sistema recibe consultas por Gmail, las registra en Airtable y utiliza IA para clasificarlas y generar un borrador de respuesta.

Según el tipo de caso, el flujo puede responder automáticamente o derivarlo a revisión humana mediante Telegram.

También se incorporó una ruta de manejo de errores para registrar fallas y notificar al equipo.

## Herramientas

Make · Gmail · Airtable · Groq · Telegram
